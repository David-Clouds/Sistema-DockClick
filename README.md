# 🏥 DocClick - Sistema de Gestión de Citas Médicas

## 📖 Descripción

DocClick es una aplicación web desarrollada en ASP.NET Core MVC que permite la gestión digital de citas médicas para centros de salud.

El sistema busca reducir los tiempos de espera, eliminar procesos manuales y facilitar a los ciudadanos la reserva de citas médicas mediante una plataforma sencilla e intuitiva.

---

## 🎯 Objetivo

Digitalizar y automatizar el proceso de gestión de citas médicas, permitiendo a los usuarios:

* Registrarse en el sistema.
* Iniciar sesión de forma segura.
* Consultar especialidades médicas disponibles.
* Visualizar horarios disponibles.
* Reservar citas médicas de manera rápida y organizada.

---

## 🚀 Funcionalidades Implementadas

### HU-01 Registro de Ciudadano

Permite a los usuarios crear una cuenta mediante sus datos personales.

### HU-10 Inicio de Sesión

Permite el acceso seguro al sistema mediante DNI y contraseña.

### HU-11 Consulta de Especialidades Disponibles

Muestra las especialidades médicas disponibles para los ciudadanos.

### HU-02 Consulta de Horarios Disponibles

Permite visualizar horarios disponibles para la atención médica.

### HU-05 Reserva de Cita Médica

Permite confirmar una cita médica seleccionando especialidad y horario.
